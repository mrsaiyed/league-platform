## T5 — Customization engine

| T-290 | Season settings saves each part of a season (name and dates, game rules, recording and statistics, standings, rosters) with its own form and command; a part's save changes only its own fields, laid over the season's rules as read fresh when it is saved, and sent with the version the page showed, so a save made after another admin's save is refused and what was typed stays in the boxes (saving again then replaces only that part's fields), and two admins saving two parts never undo each other; after the first final game a change that moves the standings is shown and saved only on "Yes" (S-1). A season's rules hold the "Points (PTS)" column only when the table is ranked by points: the rules format refuses it otherwise, as it refuses a ties column where ties cannot occur, and Season settings shows that refusal beside the columns in its usual way | Agreed (delegated) | |
