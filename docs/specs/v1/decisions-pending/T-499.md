## T4 — Keeping leagues apart, sign-in, security

| T-499 | The start-up guard counts every security-definer function not on the reviewed list, of any return type (trigger and event-trigger functions included), in every schema the login or a role it may become has USAGE on, whether or not it holds EXECUTE, and still any it may run in any other schema. PostgreSQL checks the right to run an aggregate's transition function (and an operator's or a cast's function) against another role than the caller, so who holds EXECUTE says nothing of who reaches the function. The printed mending is `alter function … security invoker`, run as its owner, since taking EXECUTE away no longer passes; a legitimate one is added to the reviewed list with its reason (the migrations' three definer trigger functions were). Technical, decided by the lead (the fix-3 brief), built by the builder. | Agreed (delegated) | |
