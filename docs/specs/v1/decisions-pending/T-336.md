## T6 — Live stats and realtime

| T-336 | The takeover question's facts (S-42, step 2.148). A game is under way when the server's game is live, which a reopened game is again; a lapsed holder of a game under way is never displaced by an opening, which is answered `held-by-other`, and only a confirmed takeover naming that holder's `since` takes it (logged as any takeover). A game not yet live is still simply opened once its holder lapsed. The holder's `lastHeardAt` is when its lease was last written, so up to about half a minute early (T-295), never before its session began; `sameAccount: true` is set by the server when the holder is the asking account on another device, never told by names. Both are optional in the reply's schema so a tracker reads an older server; a tracker opened before this release fails to read a reply carrying them, so a release should not fall during a takeover (T-127 covers commands, not this reply) | Agreed (delegated) | |
