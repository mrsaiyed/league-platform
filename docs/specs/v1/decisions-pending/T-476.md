# T-476

New

## T9 — Quality and maintainability

| T-476 | In every schema but PostgreSQL's own (`pg_catalog`, `information_schema`, `pg_toast`), the start-up guard refuses by name any table, view, materialized view or foreign table that no migration made and that the login, or a role it may become, can read (the use of its schema and SELECT on it or on any of its columns), with `revoke select on table … from` every holder the login reaches, or `drop …` when it reads it as the owner; what the login cannot read, such as an extension's own objects, is let be | Agreed (delegated) | |
