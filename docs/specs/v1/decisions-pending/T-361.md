## T6 — Live stats and realtime

| T-361 | An upload goes through the tracker's own commands door (`sendTrackerCommands`), in batches of one protocol version and at most 50, in the copy's order. The door is first asked under a session that holds nothing, which saves nothing and answers `duplicate` for whatever the server has: a copy with nothing new is answered at once, so a second upload changes nothing and the device scoring now is not disturbed. Otherwise the game's session is taken as opening takes it, on a device of the upload's own (never a tracker's session on the same device): a game another device holds is answered `held-by-other` and is taken only with the takeover answer naming that holder (S-42). The new commands go under that session, which is released at the end | Agreed (delegated) | |
