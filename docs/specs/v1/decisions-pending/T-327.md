## T6 — Live stats and realtime

| T-327 | What a device keeps belongs to one person (the lead's decision, step 2.38 fix round, review M1). Every kept page, kept game and kept play carries the id of the person it was kept for. The device holds a mark of who is signed in here (an id, no secret: `device-account.ts`), written by every signed-in page load that reaches the network (pages with the account's sign-out form; the tracker page once the server answers its opening) and so by signing in, deleted by signing out. With no network a kept page or kept game is shown only when its owner is the marked one, otherwise the plain offline page. When another person's id replaces the mark, the earlier person's kept pages and games are forgotten (the worker's forget path); their unsent plays stay on the device, hidden, and are sent only when that person signs in here again. A batch of version 2 says whose plays it carries (`accountId`): the client never sends another person's plays, and the server refuses a batch whose stated maker is not the account of its session (the session decides; the stated maker can only refuse). Plays kept before this release name nobody: never sent, listed to nobody. Before this, with no signal a kept page opened for whoever held the device. | Agreed (delegated) | |
