## T8 — Scale, reliability and operations

| T-302 | `scripts/check-test-copy.mjs <address>` checks a test copy from outside, read-only and with no secret: it reads no environment, takes https or plain http to this computer only (localhost, 127.0.0.1) with nothing after the address, follows a redirect only on the same host (5 at most), and waits at most 10 seconds for each answer. It sends GET requests and one POST, the "be this person" form for a person no copy has, to `/signin/made-up-people` and to `/signin/no-such-page`. "Do not index" is the `X-Robots-Tag: noindex` header and the page's own mark on the front page, the sign-in page, a made-up league's address and a page that does not exist, and the header with "every robot, nowhere" on `robots.txt`. "Exactly as `/signin/no-such-page`" is the same status and the same body once three things are put in one place: the page's one-time script nonce (read from the answer's own policy), the address's last name, and the order of the streamed data pieces; headers are not compared, as a host's proxies add their own to every answer. The action's id is new at every build, so it is given (`--action-id`, or `--manifest` with the build's `server-reference-manifest.json`); without it that line fails as not checked. Exit code 0 only when every line passed, 1 when one failed, 2 when it refused | Agreed (delegated) | |
