## T9 — Quality and maintainability

| T-470 | A league table is one with a `league_id` column, or the table such a column points at (the leagues), in any schema but the server's own, and also every table the migrations' catalog lists as one, whatever its columns now: a listed table that is missing, or whose league column is gone or renamed, is refused by name (a rename with the `alter table … rename column` that restores it); a right policy on one is a migration's own, compared by table, name, permissive or restrictive, command, roles and both rules, with `public.` and spacing not counted; any other policy is refused by name with `drop policy`, a changed one with the `alter policy` that restores it | Agreed (delegated) | |
