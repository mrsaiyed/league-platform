## T4 — Keeping leagues apart, sign-in, security

| T-505 | The known-device cookie (srl_known): at each successful sign-in (password, code, Google) the server adds an HMAC-SHA-256 tag of the device cookie's id and the address, under a key derived from SESSION_SECRET or SUPABASE_SECRET_KEY (one made up per process without either). It is http-only, holds no address and no account, keeps the newest 5 tags, and vouches only when the device cookie and the address typed give a tag it holds. The sign-in service hears only the vouched device id (knownDevice) | Agreed (delegated) | |
