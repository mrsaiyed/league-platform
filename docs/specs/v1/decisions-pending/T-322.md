# T-322

New

## T6 — Live stats and realtime

| T-322 | The update rule of T-127 and T-319, made exact (the lead's decision, step 2.38 part 4): a game holds a new release back only while it is open as a scorekeeper means it: it is not final, or plays of it still wait on this device to be sent. A final game with nothing waiting holds nothing back, nor does a game the device has let go (no longer in its store of opened games), whatever of it waits. When the store cannot be read, a release waits; when only the queue cannot be read, every kept game counts. Before this a release waited while the store held any game at all, which in practice meant until signing out or the 14-day clean-up. Rule: `gamesHoldingBack` (tracker-worker-rules.ts), read by the worker from the opened games store and the queue. Also (step 2.38 part 4, T-253): a device whose own session ended while it was away and which is given a new one sends the taps still waiting under the old one under the new one when nobody else scored since the state it last knew; otherwise they are listed as not saved. | Agreed (delegated) | |
