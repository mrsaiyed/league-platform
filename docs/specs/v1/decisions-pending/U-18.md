This is a safety rule, the one place we do not leave the choice to the admin, and it makes the settings screen's sentence ("A league with children in it is never shown by search engines, whatever this says") true. It can never miss a page that shows a child's name, now or when a new page is added; such a league loses only search traffic it should not want.
