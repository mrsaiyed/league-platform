## T4 — Keeping leagues apart, sign-in, security

| T-449 | A league that is missing costs the league gate the same reads, in the same order, as one that is there but hidden from this person (step 2.223). A signed-in person's request whose league is not found (no such short name or id, or in the bin) still reads their access, once, in the same place, for the one id no league has (`noLeagueId`, all zeros; `readAccessOfNoLeague` in `apps/web/src/server/league-gate.ts`), and the answer is thrown away. A visitor's request reads no access either way. Pages (`resolveLeagueRequest`) and endpoints (`resolveLeagueApi`) both do it; `league-gate-hidden.test.ts` counts the reads. Below the gate, the access query itself may stop earlier for a league that is not there: not yet made equal | Agreed (delegated) | |
