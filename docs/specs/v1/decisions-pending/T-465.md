## T4 — Keeping leagues apart, sign-in, security

| T-465 | The public player key's secret (T-462) is, in this order: SESSION_SECRET when it is set; else, where the app runs on a real database, a secret derived by HKDF-SHA-256 under a label of its own from the sign-in service's secret key (SUPABASE_SECRET_KEY, which staging and production already require and no visitor sees); else, only on made-up data with neither, a random secret made when the server starts. So every server process with the same settings gives the same key for a game, the app never fails to start for want of SESSION_SECRET, the founder adds no setting, and nothing of the secret is logged (step 2.225) | Agreed (delegated) | |
