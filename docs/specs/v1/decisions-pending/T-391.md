## T6 — Live stats and realtime

| T-391 | A play of a statistic the season does not keep is refused about that tap alone (S-93, step 2.241): the server judges each tap by the season's "Statistics kept" as it stands (statisticsKept with the season's rules, as the public pages count them), not the rules the game kept when it went live. Points and fouls are kept in every season tracked live, so only a turnover and a team turnover are judged; a tap that takes one back is always taken (T-394). The refusal's code is statistic-not-kept, said only to a tracker that names it in the batch's knownRefusals (a tracker of this release, version 2 batches and the send-these-plays batches); any other batch, version 1 and the copy upload included, is answered rule with the same message, since a tracker of an earlier release reads an unknown code as no answer and would send its queue again for ever. The tracker's queue sets both codes aside and lists the tap under the plays not applied, and sends the rest. A copy upload holding such a play is answered uploaded, the play counted in notTaken, never damaged. | Agreed (delegated) | |
