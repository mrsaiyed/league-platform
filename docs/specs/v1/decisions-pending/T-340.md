## T3 — Data model

| T-340 | The format a game is given before it starts is a column of its own, `games.given_format` (migration 0026): a versioned document of the format part of a season's rules (periods and lengths, overtime, the clock, the fouls and the timeouts), kept apart from `format`, the rules fixed at the start. The rules fixed are the season's with the given format in their place; marking the game not started empties `format` and keeps `given_format`; a trigger refuses a change to it once the game has started | Agreed (delegated) | |
