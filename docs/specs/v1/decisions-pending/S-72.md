## Decided for you, waiting for your yes

| S-72 | Whether the clock runs on after an End game is taken back | No. "Take back End game" is offered while the End has not reached the league (no connection), on the device alone and with no reason asked. Taken back, the game is live again exactly as it was, with the clock stopped at the moment End game was tapped, as it is after a Reopen (S-36), and the screen says "End game taken back. The game is live; the clock is stopped." The scorekeeper starts it when play goes on. Why: the commonest wrong End is a tap meant for Pause, so stopped is what they wanted; and a clock that had run on unseen behind the final panel would have to be set back by hand | A small change in one rule |
