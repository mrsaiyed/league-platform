## T6 — Live stats and realtime

| T-344 | A device never starts or plays a game on a format that is no longer the game's. With signal, "Confirm and start scoring" reads the game's format again first; if it is not the one shown (or not the one the device would play) the game is not started: the new rules are shown with one line saying the format was changed, and the scorekeeper confirms again. With no signal the device starts on what it has: bad signal never blocks a scorekeeper. Whenever the server's answer brings other rules than the device plays (another device changed the format, or taps waited offline on the old one), the device takes the server's at once and says in one line, until dismissed, that the format of this game was changed and what it is now; a change saved on the device itself is said back by its form instead | Agreed (delegated) | |
