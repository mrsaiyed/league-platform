## T2 — Repository and code structure

| T-454 | `npm run check` fails on a way into a league that skips the league gate (step 2.223; `scripts/structure/league-gate.mjs`). A route under `apps/web/src/app/api/v1/leagues/` exports only handlers it writes itself (GET, HEAD, OPTIONS, POST, PUT, PATCH, DELETE, every one checked) and Next.js's settings: no re-export, list, `export *`, default or other name (review M3). In each handler `leagueEndpoint(` is a statement of the handler's own body (not under an `if`, a loop or another call), and before it nothing is awaited but the route's `params` and nothing reads the body (`jsonBody(`, `.json(`, `.formData(`, `.text(`, `.arrayBuffer(`, `.blob(`, `.body`, by any name). A `'use server'` file must pass the page gate (`loadLeaguePage(`, or `performScheduleAction(`) in each function it exports, directly or through a function of its own file or of a file it imports from its own folders; the files that may not, sign-in's two and the invitation's (an invitee must reach a draft league), are listed in the rule with why. A `'use server'` inside a function (an action inline in a page or component) is refused anywhere in `apps/`. Comments and strings do not count. `tests/structure-checks.test.mjs` plants each kind. What it still cannot catch, said plainly: in a server action it checks that the gate is called, not when (under an `if`, or after the action has changed something, passes); a route handler that passes the request to a function of its own before the gate without awaiting it passes, as what that function reads is not followed; a gate whose answer is not looked at passes; a league reached outside these two kinds of file is not this rule's (`npm run test:web` and `league-gate-hidden.test.ts` prove the pages) | Agreed (delegated) | |
