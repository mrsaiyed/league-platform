## T4 — Keeping leagues apart, sign-in, security

| T-462 | A player in a game's public snapshot is known by a key, never by a person's or roster place's id: HMAC-SHA-256 of a fixed label, the game's id and the player's id under the key's secret, in T-465's order (SESSION_SECRET when set, else a secret derived by HKDF from SUPABASE_SECRET_KEY, else random on made-up data only), cut to 16 bytes; the same all through one game, different in every other, and not to be worked back. It is made in one place on the server (`apps/web/src/server/player-key.ts`) and handed to core (step 2.225, finding D-M4) | Agreed (delegated) | |
