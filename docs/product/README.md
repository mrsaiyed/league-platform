# Product documentation

The active baseline is [Platform specifications v0.7](platform/README.md). It describes the shared product, with Al-Hadi varsity scoring as the immediate implementation use case. The [engineering specification](platform/engineering/README.md) gives the concrete repository, data, customization, security, transaction and operating design behind the product requirements.

The earlier school proposal and combined v0.1–v0.3 specifications are preserved under [Al-Hadi intramural](../initiatives/alhadi-intramural/README.md). They are historical inputs, not an alternative active specification.

Use the platform document map to review one area at a time. Approved changes belong in the relevant section and decision register; customer requests should become configuration, a supported reusable capability, or an explicitly scoped integration.

The immediate implementation is [Al-Hadi varsity scoring](../initiatives/alhadi-varsity/README.md), a reusable team-managed game workflow in an outside competition. The broader product specifications remain authoritative; intramural work is preserved for later.
