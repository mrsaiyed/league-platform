| T-366 | "Put the sheet back as it was" is the command `games.put_sheet_back` (`games.correct`, the game's scope, as reopening): it writes back every line the game's newest correction kept (T-365), with that result, how it was recorded and its overtime, and the game is decided again, so standings and totals follow (`games.finalized`). It changes a decided game, so it writes a correction of its own with a reason (S-7, 0011's guard), whose `before` keeps the lines it replaces. It is allowed only while the game is decided and its newest correction is the reopen that kept a sheet: a put back is itself a correction that leaves the game decided, so once one is saved, or the game is reopened again, it is refused (`newer-save`, `no-sheet-kept`; `game-not-decided` while reopened). It carries the game's version (T-46), so a double tap writes one correction and one activity entry | Agreed (delegated) | |
